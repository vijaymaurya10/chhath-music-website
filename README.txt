CHHATH MUSIC — PROFESSIONAL V2
================================

How to run:
1. Extract this folder.
2. Open the folder in VS Code.
3. Open index.html with Live Server (recommended).
   Or double-click index.html for a basic local preview.

Included:
- Professional Chhath-inspired dashboard UI
- 10 bundled MP3 tracks in songs/
- Search, sorting, favorites and downloads
- Shuffle, repeat, next/previous, progress and volume
- Light theme by default with theme toggle
- Responsive mobile sidebar and player
- Settings modal + saved preferences
- Polished hero buttons, animated Chhath-gold heading and modern cards
- About Us profile section with creator photo
- WhatsApp, LinkedIn and Instagram social buttons
- Keyboard shortcuts: Ctrl/Cmd+K search, Space play/pause, Alt+Left/Right previous/next
